# R2 handoff · Loot is never lost (done, C1–C3; C2 and C3 share one commit)

- **Landed.** Coins and xp fly home to a living hero within `PICKUP.homeRange` (1400) after the bounce; beyond it, or with the hero down, coins bank and xp is owed at `PICKUP.farXp` (0.5), paid when the hero stands (`Player.addXp` ignores a dead hero). A full pool credits the same way. Dawn sweep banks cargo on claimed ground; routed walkers' coins and cargo bank straight into the sweep; cargo on claimed ground does not rot from the warning to dawn; one popup line `swept from the field: +N kind, …`.
- **Contracts.** `PickupManager.sweepField(): ResourceBag` (cargo on claimed ground; also banks any coins left anywhere, which are not in the bag). `WaveManager.nightLog: NightLog`, `NightLog = { wave, kills, coins, swept: ResourceBag, sacked }` exported from `core/Events.ts`; bus `'night:summary': NightLog`, emitted at the end of `endNight`, after `wave:cleared`. Pure helpers in `PickupManager.ts`: `sweepPickups(items, claimed, take)`, `rollLoot(def, greed, into)`, `sweptLine(bag)`, `isCargo(kind)`.
- **Deviations.** `nightLog.coins` = `res.totalGathered.coins` diff since dusk + the night reward (the reward is banked uncounted); so it includes any tithe (R1) banked during the night if R1 counts it as gathered. `collectAllInRadius` is removed (no callers left). Kills count every `notifyKilled(fromWave)`, so a boss killed after dawn bumps the already-emitted log object (harmless).
- **R4:** increment `this.scene.waves.nightLog.sacked++` on a sack; a fresh object is made each dusk in `openLog()`.
- **Merge notes.** WaveManager edits: 3 import lines after the `ENEMIES` import, `nightLog`/`duskCoins` fields after `wavesCleared`, one line `this.openLog()` right after `this.wave++` in `beginNight`, and `notifyKilled`/`openLog`/`rout`/`endNight`. `PICKUP` extended in place. `night:summary` added after `wave:cleared` in `core/Events.ts`.
- **Verified.** 167 tests (new `tests/loot-home.test.mjs`), typecheck, world lint green; harness smoke: 5 kills at 2000 px banked +26 coins with no pickups, xp paid at half; night 1's `night:summary` came out `{ wave: 1, kills: 3, coins: 107, swept: { wood: 25 }, sacked: 0 }`.
